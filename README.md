# what-i-read-papers

This is to record what I read and summaries.

## Structure

- `ai/` — AI research papers
- `economics/` — Economics research papers
- `interdisciplinary/` — Interdisciplinary papers (neuroscience, linguistics, cognitive science, etc.)

## Naming Convention

Summary files are named: `YYYY-MM-DD-author-et-al-year-summary.md`

Example: `2026-06-01-bohren-et-al-2019-summary.md`

## Workflow

1. Download PDF to the corresponding directory (`ai/` or `economics/`)
2. Convert to markdown: `markitdown paper.pdf -o paper.md`
3. Read the markdown and write a summary
